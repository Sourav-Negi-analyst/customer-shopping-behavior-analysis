# Customer Shopping Behavior Analysis

## Project Overview
This project analyzes customer shopping behavior to understand purchasing patterns, product preferences, customer satisfaction, and shopping trends.

The project demonstrates an end-to-end data analysis workflow using Python, SQL, and Power BI.

## Business Objectives
- Identify the most frequently purchased items.
- Compare average purchase amounts across product categories.
- Analyze shopping behavior by gender and age group.
- Compare subscribers with non-subscribers.
- Explore the relationship between discounts and purchase amounts.
- Identify common payment methods and purchase frequencies.
- Compare customer ratings across product categories.

## Tools and Technologies
- **Python:** Pandas, NumPy, Matplotlib, Seaborn
- **SQL:** Data querying and business analysis
- **Power BI:** Interactive dashboards and data visualization
- **Jupyter Notebook:** Data cleaning and exploratory data analysis (EDA)

## Project Workflow
1. Data cleaning and preparation using Python.
2. Exploratory data analysis (EDA) and visualization.
3. Business analysis using SQL queries.
4. Interactive dashboard development using Power BI.
5. Interpretation of findings and business insights.
