# Customer Shopping Behavior Analysis

## Project Overview
This project explores customer shopping behavior to understand purchasing patterns, product preferences, customer satisfaction, and factors that influence purchase decisions.

## Objectives
- Identify the most frequently purchased items.
- Compare purchase amounts across product categories.
- Analyze shopping patterns by age group and gender.
- Compare subscribers and non-subscribers.
- Explore discounts, payment methods, and purchase frequency.
- Examine customer ratings across categories.

## Tools and Technologies
- **Python:** Pandas, NumPy, Matplotlib, Seaborn
- **SQL:** Data querying and business analysis
- **Power BI:** Interactive dashboards and data visualization
- **Jupyter Notebook:** Data cleaning and exploratory data analysis

## Project Workflow
1. Data cleaning and preparation using Python.
2. Exploratory data analysis (EDA).
3. Business analysis using SQL queries.
4. Dashboard development using Power BI.
5. Interpretation of findings and business insights.
